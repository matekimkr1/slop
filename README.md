# GTO 레인지 뷰어 — Section 1

**https://matekimkr1.github.io/slop/**

MTT 30bb ChipEV · 18개 노드를 히어로 포지션별(EP/MP/LP/SB/BB)로 정리한 모바일 뷰어 + 핸드 조회기.
포지션 매핑: **EP=UTG · MP=HJ · LP=BTN**

## 기능

- **핸드 조회** — 자리 → 상황 → 핸드를 고르면 정답 액션과 혼합 비율을 즉시 표시. 차트에서 해당 칸을 노란 테두리로 강조.
- **모바일 최적화** — 좌측 차트와 우측 요약표를 세로로 분리해 스택. 원본 JPEG을 CSS로 크롭하므로 재인코딩 손실 없음.
- **확대** — 네이티브 핀치줌 + 차트 100~400% 슬라이더.
- **뒤로가기** — Android 하드웨어 뒤로가기로 목록 복귀 (History API).

## 데이터 (`ranges.json`, 55KB)

18노드 × 169핸드 = **3,042칸**의 액션 빈도. 런타임 AI 호출 없음.

칸 하나당: `{"R":46,"C":54}` = 레이즈 46% / 콜 54% 혼합.
`_r` 키는 도달률(예: `_r:24` = 이 핸드가 해당 상황에 24%만 도달).
`null` = 미도달(앞 단계에서 이미 폴드되는 핸드).

구성: 완전도달 2,547 · 부분도달 29 · 미도달 466

## 추출 방법

원본 스크린샷의 13×13 격자에서 **픽셀 색을 직접 계수**. AI 판독이 아니라 결정론적 측정이라 재현 가능.

| 색 | RGB | 액션 |
|---|---|---|
| 진한 벽돌 | (114,39,34) | 올인 |
| 밝은 빨강 | (221,77,69) | 레이즈 |
| 초록 | (115,183,110) | 콜 |
| 파랑 | (77,124,180) | 폴드 |
| 검정 | (30,30,30) | 미도달 |

- 칸 내부 **가로 분할 비율 = 액션 믹스**, **세로 채움 비율 = 도달률**
- 격자 좌표는 고정값 (left=28, 열 128px, 행 89px) — 구분선 실측으로 2px 이내 검증
- 흰 글자 픽셀은 분모에서 제외

## 검증

**① 자동 대조** — 원본 화면 우측 Actions 패널에 적힌 집계 %와, 추출값을 콤보 가중 합산한 값을 비교.
→ 평균 오차 **0.55%p**, 18개 노드 중 **17개가 1%p 이내** (최대 1.4%p)

**② 교차 검증** — DB를 모르는 Claude 에이전트에게 확대한 칸 이미지만 주고 독립 판독시킴.
→ 1차 54칸 53/54, 2차 61칸(다른 표본) **60/61 일치**. 불일치는 46:52 vs 50:50 경계 케이스뿐.

부분도달 셀(위는 검정, 아래에 색 띠)은 서로 다른 에이전트가 독립적으로 관측한 도달률과 1~3%p 내로 일치.
